01一句话结论

中国社交媒体平台TikTok因未成年人数据处理与隐私默认设置问题，连续被英国和爱尔兰监管重罚，最终被欧盟罚款近9亿欧元（约9.7亿美元）。对中国出海企业而言，产品默认设置和未成年人保护已成为合规红线，不能只靠事后补救。

02发生了什么

2019年后，TikTok凭借算法推荐和短视频内容在欧美青少年中迅速流行，成为全球增长最快的社交平台之一。随着用户量激增，平台对未成年人数据的处理方式逐渐引发欧美监管关注。2020年8月，美国政府以国家安全为由，签署两份针对字节跳动的行政令，要求其出售TikTok美国业务，否则将面临禁用。9月20日，美国商务部宣布禁止TikTok的新下载，TikTok的“中资背景”由此成为欧美舆论与监管关注的焦点。

面对压力，TikTok于2021年1月宣布一系列针对青少年的隐私与安全调整：将16至17岁用户作品的下载默认设置由“开”改为“关”，15岁及以下用户的视频不再允许被下载，并限制该年龄段的私信与直播功能。这些调整旨在回应外界对未成年人隐私保护的质疑，但欧美监管并未因此放松。

2023年4月，英国信息专员办公室（ICO）认定TikTok“未能合法使用儿童个人数据”，也“没有做足够”去阻止未满13岁儿童使用平台，开出1270万英镑（约1,580万美元）罚单。ICO估计，约有一百万未满13岁儿童被不当允许访问平台，其个人数据被收集和使用。TikTok回应称不认同该决定，但“欣慰”罚款已降至上年提议金额的一半以下，并表示将评估下一步。

2023年9月，欧盟主监管机构——爱尔兰数据保护委员会（DPC）认定TikTok在儿童数据处理上违反GDPR多项条款，罚款3.45亿欧元（约3.7亿美元），并责令三个月内完成整改。DPC指出，TikTok当时的注册流程默认将儿童账号设为公开，视频、评论及“合拍”“缝合”等功能也默认开启，“家庭配对”功能未核实配对者身份。TikTok回应称“尊重但不同意”处罚决定，强调相关问题在调查前已整改（如将16岁以下账号默认设为私密），并考虑上诉。

2024年10月，美国哥伦比亚特区检察长与13位州检察长联合对TikTok提起诉讼，指控其误导用户、淡化应用对未成年人心理健康的危害。诉讼还指控TikTok通过无牌照虚拟货币“TikTok Coins”从经济上剥削儿童，儿童用真钱购买虚拟币，公司从中获得高达50%的分成，而年龄核验薄弱让儿童可轻易完成交易。TikTok未回复置评请求，但早前声明不同意这些指控，认为许多内容“不准确且具有误导性”。

与此同时，澳大利亚隐私监管机构也对TikTok的数据收集（包括广告像素）展开问询，决定是否启动正式调查。2025年5月，欧盟监管机构再次以数据保护为由，对TikTok罚款5.3亿欧元（约5.7亿美元）。整个过程中，TikTok采取了“先整改、后抗辩”的策略，持续调整产品设置，并公开披露移除疑似未成年账号的数量以展示执行力度。

04风险是怎么形成的

议题定位：主议题 S10 数据隐私；副议题 S09 消费者权益与营销

根因链：视频社交平台依赖行为数据、偏好和影像内容来定制服务与广告变现 → 青少年用户占比高且对分享风险认知较弱 → 儿童账号曾被设为公开，评论、“合拍”“缝合”等功能默认开启 → 年龄门槛和家庭配对核验未能充分阻断未成年人风险 → 英国和爱尔兰监管认定儿童数据处理违法并重罚 → 美国诉讼进一步把争议扩展到虚拟币、直播消费和误导用户指控

1. 结构性根因：数据密集型商业模式叠加青少年用户结构〔S10、S09〕 TikTok的服务逻辑建立在使用数据、行为数据、偏好、好友和联系人等信息之上，用于提供服务、个性化体验和定向广告，这使个人数据成为产品增长和商业化的底层资源。与文字或图片平台相比，TikTok以视频为核心，用户是在录制和上传自己，专家还指出该应用主要受青少年欢迎，而青少年可能更少意识到自己分享了什么。因此，风险不是单次数据泄露造成的，而是数据密集型平台在未成年人场景中天然放大了隐私和消费者保护压力。

2. 产品设计层：默认公开把儿童隐私风险嵌入注册和互动流程〔S10〕 爱尔兰数据保护委员会认定，TikTok当时的注册流程会让儿童用户账号默认公开，任何站内外用户都可查看其发布内容。监管还指出，儿童用户的视频、评论以及“合拍”“缝合”等功能也默认开启，这使儿童内容从一开始就处在更高可见度和互动风险中。这类设计缺陷触及GDPR下“默认数据保护”和“设计中的数据保护”要求，因而从产品选择转化为合规违法问题。

3. 治理层：年龄门槛和监护控制没有形成有效内控闭环〔S10〕 英国信息专员办公室认定，TikTok没有做足够工作来确认谁在使用平台，也没有采取充分行动移除未满13岁的儿童用户。该机构估计约一百万名13岁以下儿童被不当允许访问平台，其个人数据被收集和使用，并可能被用于追踪、画像和推送内容。爱尔兰监管虽未就年龄核验方法本身作出违规认定，但认为TikTok没有适当考虑13岁以下儿童进入平台后的风险，技术和组织措施不足。

4. 外部环境与应对滞后：儿童数据执法叠加跨境安全审查〔S10〕 美国政府曾以TikTok由中国公司拥有、构成安全风险为由要求字节跳动出售美国业务或面临禁用，使其数据治理问题被置于更高政治和监管关注之下。TikTok随后调整了青少年隐私与安全设置，例如将16至17岁用户作品下载默认改为关闭，并限制15岁及以下用户下载、私信和直播功能。但这些调整没有消除既往期间的监管责任，英国监管罚款1270万英镑（约1,580万美元），爱尔兰监管罚款3.45亿欧元（约3.7亿美元）并要求三个月内整改，另有欧盟监管机构因数据保护再罚5.3亿欧元（约5.7亿美元）的报道。

5. 放大机制：美国诉讼把争议延伸到虚拟币和儿童消费剥削（指控，尚未裁决）〔S09、S10〕 哥伦比亚特区检察长与13位州检察长起诉TikTok，称其误导用户，淡化应用对儿童和年轻人心理健康与福祉的不利影响。哥伦比亚特区检察长还指控TikTok通过类似赌场筹码的未获许可虚拟货币和直播功能在经济上剥削儿童，诉讼称儿童可用真钱购买TikTok Coins，公司可获得购买收入的50%。诉讼还称儿童能轻易绕过薄弱的年龄核验完成交易；TikTok未回复该报道置评请求，但此前声明不同意这些指控，认为许多内容不准确且具有误导性。

05如果你是……

董秘

  • 应主动向投资者披露各国监管进展与罚款金额，说明整改计划及其对财务和声誉的影响。
  • 应在年度报告中单独列示合规风险，披露与GDPR、英国数据保护法相关的整改进度与外部审计结果。

合规负责人

  • 应在产品设计阶段介入，确保所有面向未成年人的功能默认关闭，符合GDPR“隐私默认保护”原则。
  • 应建立可审计的年龄核验机制，并对虚拟货币、直播打赏等变现功能进行合规影响评估，防止触及货币传输与消费者保护法规。

ESG 负责人

  • 应将未成年人数据保护纳入ESG报告重大性议题，披露整改措施及第三方验证结果。
  • 应对供应链中的第三方广告工具、数据追踪像素等进行合规筛查，确保无违规数据外流。

战略负责人

  • 应在欧洲市场优先选择数据本地化和第三方审计能力强的合作伙伴，降低地缘政治与合规风险。
  • 应重新评估以青少年为主的用户增长策略，考虑调整产品定位与市场布局，减少对高风险群体的依赖。

公关负责人

  • 应在收到监管处罚后，第一时间发布公开声明，明确整改时间表与第三方验证承诺，避免“先否认、后整改”的被动形象。
  • 应主动与家长、学校、儿童保护组织沟通，公开透明披露未成年人保护措施，争取社会支持。

今天的启示：数据隐私与未成年人保护已成为全球社交平台出海的合规底线，产品设计、合规、沟通需前置一体化。

06出海爱尔兰中企自查清单

  1. 我们的关键零部件或应用产品在设计阶段，是否已将“默认私密”作为未成年人账号的强制要求？有无书面记录对照GDPR“隐私默认保护”原则？
  2. 我们是否有可审计的年龄核验技术方案，并定期向爱尔兰数据保护委员会（DPC）报备？最近一次技术评估报告是什么时候？
  3. 我们的虚拟货币、积分、打赏等变现机制，是否已评估其在爱尔兰是否触及《消费者保护法》或货币传输类监管要求？
  4. 我们是否对在建项目和本地工厂的第三方广告工具、数据追踪像素进行了合规筛查？有无外部合规顾问出具的风险评估报告？
  5. 我们是否已建立与当地学校、家长组织、儿童保护非政府组织的定期沟通机制？有无针对未成年人保护的社区反馈渠道？
  6. 我们是否已将数据本地化和跨境传输合规要求纳入与本地云服务、数据中心的合同条款？合同是否符合GDPR跨境数据传输机制？
  7. 我们的合规与法务部门是否定期跟踪爱尔兰DPC、欧盟EDPB关于未成年人数据保护的最新执法案例和指导意见？有无内部培训记录？
  8. 我们是否在年度ESG或可持续发展报告中，单独披露未成年人数据保护和隐私合规的整改进展及第三方验证结果？
