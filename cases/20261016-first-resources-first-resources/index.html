01一句话结论

新加坡棕榈油种植商First Resources因印尼特许区被检测到火灾和烟雾，被绿色和平报告点名，新加坡政府已启动调查。对中国出海企业而言，跨境ESG指控与监管调查可能迅速升级，影响声誉、融资与合规成本。

02发生了什么

2025年8月至9月，绿色和平通过卫星监测，发现印尼西加里曼丹等地多处棕榈油种植园区出现火灾和烟雾。10月5日，绿色和平发布调查报告，点名新加坡上市公司First Resources、Bumitama Agri，以及私人公司First Borneo Plantations，称其相关特许区在上述期间检测到火灾和烟雾。报告还具体指出，Kayung Agro Lestari运营的西加里曼丹特许区为热点之一，该公司为印尼棕榈油生产商Austindo Nusantara Jaya（ANJ）的子公司，而ANJ已于2025年5月被First Resources收购。此举意味着First Resources的风险暴露已扩展至ANJ及其子公司管理的区域。

报告同时将与Bumitama Agri有关联的Damai Agro Sejahtera，以及与First Borneo Plantations有关联的Arjuna Utama Sawit列为检测到火灾和烟雾的相关公司。First Borneo Plantations与新加坡注册公司Chancellor Oil存在所有权联系，后者曾为泰国能源公司PTT持有，2025年已转让给Premier Palmoil Energy。

面对媒体和投资者的关注，First Resources于10月15日作出回应。公司强调，卫星在种植园特许区内或附近检测到热点，并不能直接认定火灾起源、责任归属或特许权持有人有意纵火，需地面详细调查。公司称，虽然在其西加里曼丹种植园特许区附近检测到热点，但许多热点经核实位于运营边界之外。First Resources还承认，一些“巨大且快速蔓延”的外部火灾确实越过边界进入其管理区域，现场消防团队已尽力扑救。

在监管文件中，First Resources将火险升高归因于严重的El Nino干旱，称极端天气导致当地社区小规模传统清地行为演变为失控野火。公司重申其“严格零燃烧政策”和“综合火灾管理”措施，包括每日卫星跟踪、无人机监视，并向受影响村庄分发17台水泵、向当地教育办公室分发数千个口罩。

与此同时，Bumitama Agri没有回复媒体查询，并于10月16日在新加坡交易所申请交易暂停，以待发布公告。在暂停交易前，其股价在午间交易时段下跌4.81%。 新加坡总理黄循财在10月15日公开表示，政府正在调查哪些公司可能对造成雾霾的火灾负责，并将在有依据时根据《跨境雾霾污染法》采取行动，同时探索与其他国家联合行动。

截至目前，First Resources否认火灾源自其种植园，Bumitama Agri尚未公开回应，新加坡方面的调查和可能的法律行动仍在进行中。

04风险是怎么形成的

议题定位：主议题 E02 空气污染；副议题 E06 重大环境事故、S06 社区关系与土地权益

根因链：棕榈油特许区与社区土地、未管理区域相邻，边界火险长期偏高 → First Resources收购ANJ后，风险暴露延伸至ANJ子公司Kayung Agro Lestari管理的西加里曼丹特许区 → 公司称严重厄尔尼诺干旱使社区小规模传统清地演变为失控野火 → 卫星监测在相关特许区内或附近发现火点、火灾和烟雾，绿色和平据此点名First Resources → 新加坡政府启动责任调查并称可依据《跨境雾霾污染法》行动，企业面临声誉和合规压力

1. 结构性根因：特许经营边界把企业暴露在外部火源和社区用地风险中〔E02、S06〕 棕榈油特许区是企业被授予使用或开发权的土地，特许权持有人对土地管理承担责任，因此外部社会对火点的归因会首先落到特许区及其经营者身上。First Resources称，其靠近特许区边界、社区自有土地和未管理区域的种植园更容易受到火险影响，这说明风险并不只来自企业内部作业，也来自周边土地使用和边界治理的复杂性。在烟霾问题上，火势和烟雾不会按产权边界扩散，企业即使主张火源在边界外，仍会因火点出现在特许区内或附近而被纳入责任审视。

2. 结构性根因：并购扩大了First Resources的地理和主体风险面〔E02、E06〕 绿色和平报告点名的Kayung Agro Lestari由印尼棕榈油生产商Austindo Nusantara Jaya的子公司运营，而ANJ在2025年5月被First Resources收购。First Resources先取得ANJ 91.17%的股权，后将持股提高至95.92%，ANJ又持有Kayung Agro Lestari 99.99%的股权，后者在西加里曼丹Ketapang拥有13,878公顷种植园。这使First Resources的ESG暴露不再限于原有资产，而扩展到新并入集团体系的ANJ及其子公司管理区域。

3. 外部环境：极端干旱使社区清地行为更容易转化为区域性火灾〔E06、S06〕 First Resources在监管文件中称，西加里曼丹火险升高与严重的厄尔尼诺干旱有关，极端天气使当地社区小规模传统清地行为升级为失控野火。如果这一解释成立，风险形成的关键并非单一火点，而是干旱、社区用地和种植园边界共同作用，使原本局部的清地火源具备快速蔓延条件。公司还承认，一些巨大且快速蔓延的外部火灾越过边界进入其管理区域，显示外部火源可以直接转化为企业特许区内的环境事件。

4. 直接诱因：绿色和平以卫星火点和烟雾点名相关特许区（指控，尚未裁决）〔E02、E06〕 绿色和平称，其通过卫星监测发现印尼相关棕榈油种植园区在8月至9月出现火灾和烟雾，并在10月5日报告中点名First Resources、Bumitama Agri和First Borneo Plantations相关特许区。报告还将Kayung Agro Lestari运营的西加里曼丹特许区列为检测到火灾和烟雾的区域之一，该公司属于ANJ体系，而ANJ已被First Resources收购。但First Resources否认可由卫星火点直接推定火源、责任或蓄意用火清地，称这些结论需要地面详细调查和对火势扩散过程的评估。

5. 应对层：企业强调零燃烧和外部起火，但未能切断被归责路径〔E02、E06〕 First Resources称其执行严格零燃烧政策和综合火灾管理，包括每日卫星跟踪、无人机监视，并在热点出现后让现场消防队在特许区外围待命。公司还表示，许多热点经核实位于运营边界之外，并向受影响村庄分发17台水泵、向当地教育办公室分发数千个口罩。这些回应能够说明公司否认蓄意纵火和展示应急动作，但在跨境烟霾场景下，公众和监管关注的是哪些公司可能对造成烟霾的火灾负责，而不是只看企业是否声明零燃烧。

6. 放大机制：跨境烟霾监管把印尼本地火灾推向新加坡上市公司层面〔E02、E06〕 新加坡总理黄循财表示，政府正在调查哪些公司可能对造成烟霾的火灾负责，并会在有依据时依据《跨境雾霾污染法》采取行动，同时探索与其他国家联合行动。这使事件从印尼特许区内外的火源争议，升级为新加坡监管和跨境执法问题，增加了上市公司面对调查、解释和合规成本的压力。同一报道链条中，Bumitama Agri在被点名后未回应媒体查询，并在股价午间下跌4.81%后申请交易暂停，显示同类指控会迅速传导至资本市场信心。

05如果你是……

董秘

  • 针对2025年10月15日新加坡总理表态和绿色和平报告，立即复核公司在新加坡交易所的ESG披露义务，查阅最新监管问询函和投资者关系邮件，准备针对火灾指控的事实说明和后续进展更新。
  • 结合Bumitama Agri因同类指控股价波动和停牌，评估本公司市值波动风险，向董事会报告潜在影响，并准备与主要投资者的沟通口径。

合规负责人

  • 依据新加坡《跨境雾霾污染法》和印尼相关环境法规，梳理公司及子公司（如ANJ及Kayung Agro Lestari）在2025年8月至9月期间的火灾应对记录，核查是否存在未披露的行政问询或潜在诉讼风险。
  • 参考First Resources承认外部火灾蔓延入园区的事实，要求运营部门补充边界火灾溯源材料，完善与社区、地方政府的火灾联防协议文本。

ESG 负责人

  • 针对绿色和平报告点名和卫星热点争议，调取2025年8月至9月所有特许区的热点监测、无人机巡查和地面核查日志，补充第三方验证报告，准备纳入下一期可持续发展报告。
  • 结合公司向受影响村庄分发水泵和口罩的事实，整理物资发放清单和社区互动记录，评估是否需更新供应链ESG尽职调查标准。

战略负责人

  • 结合2025年5月收购ANJ导致风险暴露扩展，复查所有新并购子公司（如Kayung Agro Lestari）近三年火灾、泥炭地和社区冲突记录，要求法务部门补充并购协议中的ESG赔偿条款。
  • 参考本案中新加坡政府跨境调查和NGO点名，评估未来在印尼等高风险区域新设或扩张种植园的选址标准，优先考虑边界清晰、社区关系稳定的地块。

公关负责人

  • 针对2025年10月5日绿色和平报告点名和卫星监测数据，提前准备“热点不等同责任、需地面核查”类回应口径，确保能快速向中英文主流媒体释疑。
  • 参考新加坡总理黄循财公开表态和The Straits Times等新加坡主流媒体报道，优先监测新加坡、印尼及国际环保NGO社交平台动态，并梳理当地社区及教育部门等利益相关方联系方式，预设沟通话术。

06出海印度尼西亚中企自查清单

  1. 我们是否已核查所有在印尼运营的在建项目、工厂及子公司，确保其环境管理措施符合《印尼环境保护与管理法》（UU No.32/2009）及地方环境厅（Dinas Lingkungan Hidup）的最新要求？最近一次合规文件更新和现场检查记录由哪个部门保管？

  2. 我们对所有印尼境内的土地使用权、特许经营权及边界划分文件是否进行了本地法律合规性复核，特别是涉及与社区土地交界的区域？法务部门最近一次与地方土地管理局（Badan Pertanahan Nasional, BPN）沟通的时间和内容是什么？

  3. 我们是否建立了针对极端天气（如El Nino）导致火灾等突发环境事件的应急预案，并已向印尼地方政府和社区备案？应急预案及演练记录是否由安环部门定期归档？

  4. 我们的供应链管理体系是否要求所有印尼本地供应商、承包商具备用工合规证明、环境合规证明（如无野火记录），并定期核验？最近一次供应商合规性抽查由采购或合规部门负责，报告存档在哪里？

  5. 我们是否已评估并满足印尼外资企业本地化用工比例、工会协商机制等劳动法规（如《印尼劳工法》UU No.13/2003）的要求？人力资源部门是否保存了与工会、社区代表的定期沟通纪要？

  6. 我们是否掌握印尼政府采购、国有企业客户或主要渠道商对ESG（环境、社会、治理）合规的具体要求，包括火灾防控、社区关系、可持续披露等？销售或市场部门是否有针对这些要求的合规文件和客户反馈记录？

  7. 我们是否建立了与印尼当地社区、宗教团体及非政府组织（NGO）沟通的常态化机制，特别是在环境敏感区域？社区关系部门是否有年度沟通计划和危机应对预案？

  8. 我们是否定期监测印尼及新加坡主流媒体、社交平台和环保NGO对公司及供应链的舆情动态，并建立了跨部门快速响应机制？公关部门是否有相关监测报告和应对流程文件？
