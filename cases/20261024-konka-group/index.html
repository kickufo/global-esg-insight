01一句话结论

中国家电制造商康佳集团因多元化扩张失焦与治理失控，四年累计亏损超200亿元、2026年被深交所终止上市，至少9名前高管被查。对中国出海企业来说，主业失守与内控失效将直接威胁生存底线。

02发生了什么

康佳集团，曾是中国彩电行业的标志性企业，1992年以“彩电第一股”身份登陆深交所，成为深圳首批上市公司之一。三十余年后，这家老牌家电巨头却迎来了被深交所摘牌的结局。

转折点出现在行业技术与市场格局剧变之际。2017年，周彬出任总裁后，提出“康佳未来不只是彩电企业”的口号，将业务从传统彩电迅速扩展到供应链管理、房地产、环保、半导体、大健康、金融投资等二十多个领域。其中，供应链管理业务虽一度贡献了六成营收，但毛利率仅有1.11%；被寄予厚望的半导体板块，2025年收入仅1.62亿元，占总营收不到2%。

业务规模表面膨胀，主业却逐渐失守。2025年，康佳实现营业收入98.35亿元，同比下降11.51%；归母净利润亏损125.82亿元，同比下降237.73%；电视业务毛利率为-2.11%，每卖一台电视都在亏钱。彩电产品结构也未能向高端升级，低端机型零售量占比高达63.2%，6000元以上中高端机型合计占比不足20%。零售量从2015年的4722万台下滑至2025年的2763万台。

治理风险随之暴露。2025年4月，子公司股东朱新明实名举报，指控周彬等高管2018年通过资金“左手倒右手”虚增利润4712万元。一年内，举报信点名的高管陆续被纪委监委立案调查：2026年1月，原党委书记周彬、原副总裁李宏韬同日被通报，随后从助理总裁到事业部高管，至少9人先后被查，涉及家电、半导体、产业园、创投等几乎所有业务线。

财务与资本市场的压力同步加剧。康佳自2021年后再未实现盈利，四年累计亏损超过200亿元。2025年末归母净资产跌至-60.83亿元，资产负债率高达133%。2026年10月16日，公司公告收到深交所终止上市决定，将在五个交易日内摘牌。

在此期间，华润集团于2025年下半年正式入主康佳，开始梳理业务架构与债务体系，推动多轮内部资产盘点与风险排查。康佳2018年以4.55亿元竞拍取得新飞电器等三家公司100%股权，退市后新飞的去向也成为市场关注焦点。针对虚增利润的举报事项，公开报道未披露公司层面的详细回应，仅有高管被查的后续进展。

04风险是怎么形成的

议题定位：主议题 G07 公司治理与高管不当行为；副议题 G03 财务造假与信息披露违规

根因链：彩电行业下行与竞争代际切换 → 管理层以大规模多元化替代主业技术升级 → 低毛利和重资产业务放大资源错配与现金流压力 → 主业亏损、连续亏损、净资产转负 → 财务虚增举报和多名高管被查引爆治理危机 → 深交所作出终止上市决定并触发摘牌后果

1. 结构性根因：存量市场收缩削弱了老牌彩电企业的容错空间〔G07〕 康佳所处的中国彩电市场已从增量竞争转为存量挤压，2025年中国电视市场零售量降至2763万台，较2016年高点几乎腰斩。在同一轮行业切换中，TCL押注面板、海信押注显示技术和芯片、小米依托IoT生态，而康佳没有形成同等清晰的核心能力，战略失误的后果因此被行业收缩放大。

2. 战略治理层：多元化扩张替代主业升级，资源配置失焦〔G07〕 2017年周彬出任总裁后提出康佳不只是彩电企业，并将业务扩展到供应链管理、房地产、环保、半导体、大健康、金融投资等二十多个领域。这些扩张未形成可支撑集团的第二曲线，供应链管理业务一度贡献六成营收但毛利率仅1.11%，半导体业务2025年收入仅1.62亿元、占总营收不到2%。

3. 经营行为层：主业被边缘化后，低端化和亏损销售同时出现〔G07〕 康佳彩电产品仍主要依赖低端机型，2025年低端机型零售量占比高达63.2%，6000元以上中高端机型合计占比不足20%。产品结构未能上移叠加竞争加剧，康佳电视业务毛利率降至-2.11%，公开报道将其概括为每卖一台电视都在亏钱。

4. 财务与内控层：利润真实性被实名质疑（指控，尚未裁决）〔G03〕 2025年4月，子公司股东朱新明实名举报，指控周彬等高管在2018年通过资金“左手倒右手”虚增利润4712万元。公开报道未披露该举报事项的公司层面详细回应或司法、监管裁决，因此该事项应界定为财务造假相关指控，而非已认定事实。

5. 治理层：高管密集被查使经营失败转化为治理危机（涉嫌，尚未裁决）（指控，尚未裁决）〔G07〕 2026年以来，原党委书记周彬、原副总裁李宏韬等至少9名前高管因涉嫌严重违纪违法被纪委监委通报调查，范围覆盖家电、半导体、产业园、创投等多条业务线。高管被查本身是已公开披露的事实，但所涉严重违纪违法仍处于涉嫌阶段，公开来源未披露最终处理或裁判结果。

6. 放大机制：亏损、负净资产和退市规则把内部风险转化为资本市场后果〔G03〕 康佳自2021年后再未实现盈利，四年累计亏损超过200亿元，2025年归母净利润亏损125.82亿元，期末归母净资产为-60.83亿元。财务恶化最终触发资本市场退出后果，康佳于2026年10月16日公告收到深圳证券交易所终止上市决定，并将在五个交易日内摘牌。

05如果你是……

董秘

  • 针对2026年10月16日深交所终止上市决定，需立即复核公司所有境内外信息披露文件，确保退市相关风险、债务重组进展、子公司（如新飞电器）经营状态在公告中充分披露，并与投资者关系部门协作准备答复材料。
  • 结合2025年归母净资产为-60.83亿元、资产负债率133%的事实，向评级机构与主要股东更新最新财务状况与治理风险说明，评估对后续融资与债务展期的影响。

合规负责人

  • 针对2025年4月被实名举报虚增利润4712万元事项，调取2018年相关资金流转、关联交易与收入确认的原始凭证，核查是否存在类似“左手倒右手”操作，并评估现有内控流程能否有效识别此类风险。
  • 关注2026年起至少9名前高管被纪委监委立案调查的情况，梳理公司历年高管任职、授权、决策流程，排查是否有待完善的合规盲区，必要时补充对关键岗位的合规承诺与离任审计条款。

ESG 负责人

  • 结合2025年下半年华润集团入主并推动多轮资产盘点与风险排查的事实，更新可持续报告中关于公司治理、反腐败、举报渠道建设的重大性评估，明确披露过往治理失效带来的整改措施。
  • 针对子公司股东实名举报事件，梳理现有内部举报与申诉渠道的实际运行情况，补充ESG报告中对举报处理流程与结果的透明度披露。

战略负责人

  • 参考康佳2017年后多元化扩张至二十多个产业、供应链管理业务毛利率仅1.11%却占营收六成的教训，复盘本公司各板块毛利与现金流数据，评估新业务拓展是否脱离主业技术与资源基础。
  • 针对2025年下半年华润集团入主康佳的案例，梳理本公司在并购、股权合作、战略投资中的大股东结构变动条款，明确遇到治理危机时的应急决策权与资产保护机制。

公关负责人

  • 针对2025年4月实名举报及2026年高管被查等舆情，制定统一媒体回应口径，聚焦公司治理整改、债务重组及主业聚焦等正面信息，避免扩散负面细节。
  • 在2026年摘牌前，主动与主流财经媒体、当地社区及利益相关方沟通，解释退市原因及后续安置安排，降低不确定性引发的舆论风险。

06来华外企自查清单

  1. 我们是否已针对中国《公司法》《证券法》《企业会计准则》等法律要求，定期复核本地法人及子公司的财务报表、收入确认和关联交易凭证？最近一次由财务或内审部门牵头的专项合规核查是什么时候？
  2. 我们的高管授权、决策流程及关键岗位离任审计，是否符合中国《公司法》及外商投资企业相关管理规定？是否有定期向董事会或监事会报告、并留存会议纪要和决策记录？
  3. 我们在华各业务板块的扩张、并购及多元化投资决策，是否经过合规、风控和财务部门的独立评估，符合中国外商投资准入负面清单及地方政府审批要求？相关尽职调查和合规文件是否齐全？
  4. 针对中国市场的采购、招投标及供应链管理，我们是否已核查所有关键供应商的合规资质（如营业执照、税务登记、用工合规证明），并定期复查？最近一次供应链合规审查的时间和结果是什么？
  5. 我们是否建立了覆盖全体员工和管理层的内部举报与申诉渠道，符合中国劳动合同法及《企业内部控制基本规范》要求？举报处理流程和结果是否有留痕、并定期向管理层汇报？
  6. 我们的信息披露、重大事项公告及对外沟通，是否严格遵守中国证监会、深交所等监管机构的要求？有无针对退市、重组、重大亏损等事项的应急信息披露预案？
  7. 我们在华工厂或在建项目是否与当地社区、行业协会建立了定期沟通机制，及时响应消费者投诉、媒体舆情及地方政府监管要求？相关记录和整改措施是否归档？
  8. 我们是否定期对中国业务的资金流转、资产负债结构和现金流健康状况进行压力测试，并向总部和本地管理层报告，预警潜在财务风险？
