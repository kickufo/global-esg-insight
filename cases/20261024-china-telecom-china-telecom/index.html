01一句话结论

中国电信运营商中国电信被安全公司Lava远程识别出32块受美国出口管制的NVIDIA B300 GPU，因芯片来源不明而被质疑合规漏洞。对中国出海企业而言，算力资产的采购与运维暴露面已成为出口管制合规的新风险点。

02发生了什么

2026年8月，一则由以色列安全公司Lava发布的调查报告经Wccftech与Tom’s Hardware等媒体广泛传播。Lava称，其在对全球公网暴露设备进行扫描时，利用NVIDIA自家的数据中心GPU管理工具DCGM Exporter，远程识别出中国电信网络中有32块B300 GPU正在运行。DCGM Exporter本是为机房内部服务器健康诊断设计，但据报道，该工具在部分部署中可被公网访问，且并不总是要求密码认证。这一配置疏漏，使得外部第三方能够直接读取到GPU型号、数量等敏感信息。

Lava的调查并未进一步揭示这些GPU的物理位置，也无法确认它们是否集中部署在某一数据中心。报道明确指出，32块GPU只是被远程观测到的部分，实际数量可能更多。媒体据此追问，是否还有更多受管制芯片分布在其他国有机构或未被扫描到的网络中。

B300 GPU是NVIDIA于2025年发布的高端数据中心产品，拥有288GB HBM3E显存、8TB/s带宽等顶级参数。美国出口管制政策规定，B300只能出售给白名单客户，且客户需承诺不转售给禁运方。Wccftech据此推断，这批GPU极有可能通过非法渠道流入中国。

NVIDIA方面的回应引发关注。其发言人对Tom’s Hardware表示，报告再次说明走私“不是一个因素”，已被两国政府拦截，并称被转移的美国产品占其部署库存不足0.5%，相对中国已有算力“只是沧海一粟”。不过，NVIDIA并未否认Lava的调查发现，仅试图淡化其影响。

类似事件并非首次发生。2025年曾有报道称，中国企业在三个月内通过走私获得了价值10亿美元的NVIDIA AI芯片。2026年8月，台湾方面因非法出口B300 GPU至中国起诉了九人。就在台湾起诉前数日，服务器厂商Supermicro确认在走私调查后解雇了数名员工，报道指走私链条涉及一家拥有GPU采购白名单资格的台湾服务器贸易公司Flying Tiger Tech。

受美国出口管制影响，字节跳动、阿里巴巴、腾讯等中国科技巨头被报道转而依赖RTX PRO 5500等非受限GPU进行AI推理。

截至目前，公开报道中未见中国电信就此事作出回应，芯片来源、采购路径与实际物理位置均未得到说明。 事件在行业内外引发广泛关注，暴露出算力资产采购、供应链合规、运维安全等多重风险。

04风险是怎么形成的

议题定位：主议题 G05 洗钱与制裁违规；副议题 G07 公司治理与高管不当行为、S11 网络安全事件

根因链：高端AI算力需求与B300出口白名单限制并存 → 受限芯片存在经白名单贸易商等渠道被转移的外部土壤 → 中国电信网络被Lava称可观测到32块B300运行但来源不明 → DCGM Exporter公网可访问且未必认证暴露资产信息 → 海外媒体将其纳入出口管制绕行叙事，引发声誉与合规审查压力

1. 结构性根因：高端算力短缺与出口管制之间形成灰色供给空间〔G05〕 B300被报道为英伟达高端数据中心GPU，因其显存、带宽和AI推理能力处于顶级水平而受到严格分销限制。 美国出口政策要求B300只能出售给白名单客户，且客户需承诺防止转售给禁运方，这使最终用户、经销商和服务器集成商之间的链条合规成为关键风险点。 同时，受出口管制影响，中国科技企业被报道转向使用RTX PRO 5500等非受限GPU进行AI推理，说明高端受限芯片与可替代算力之间存在性能落差和需求张力。

2. 外部环境：受限GPU走私链条被报道已具备跨境组织化特征（指控，尚未裁决）〔G05〕 Tom’s Hardware称，2025年曾有报道称中国企业在三个月内走私获得价值10亿美元的英伟达AI芯片，这表明相关风险并非孤立个案。 该媒体还报道，2026年8月台湾方面因非法出口B300 GPU至中国起诉九人，且服务器厂商Supermicro在走私调查后确认解雇数名员工。 报道称相关链条涉及一家拥有GPU采购白名单资格的台湾服务器贸易公司Flying Tiger Tech，显示白名单采购主体本身也可能成为转移风险的节点。

3. 治理层：算力资产采购来源与合规留痕未能在公开层面自证〔G07、G05〕 截至报道发布时，公开信息未说明中国电信网络中被识别B300的采购路径、供应商、合同链条和实际物理位置。 对运营商和云数据中心主体而言，GPU并非普通IT耗材，而是可能受到出口管制约束的战略算力资产，来源不明会直接转化为制裁合规和供应链尽调疑点。 公开报道也未见中国电信就此事作出回应，使外部只能围绕安全公司发现和媒体推断来解读事件。

4. 行为层：企业网络被指运行32块受限B300但来源未明（指控，尚未裁决）〔G05〕 以色列安全公司Lava称，其通过英伟达DCGM Exporter工具，在中国电信网络中远程识别出32块B300 GPU正在运行。 报道同时说明，Lava无法确认这些GPU的确切物理位置，也无法判断它们是否集中部署在某一个数据中心。 Wccftech据美国出口管制规则推断，这批GPU很可能通过非法渠道流入中国，但公开报道尚未披露监管机构对此作出裁决。

5. 直接诱因：运维监控工具暴露把内部资产变成外部可见证据〔S11、G07〕 DCGM Exporter原本用于数据中心服务器健康和性能监控，但报道称该工具在部分部署中可以从数据中心网络之外访问。 Tom’s Hardware还称，该工具并不总是要求密码认证，这使外部第三方能够读取GPU型号、数量等资产信息。 这一运维配置问题把原本需要内部台账、采购记录或现场检查才能确认的算力资产，转化为可被安全公司远程扫描和媒体引用的公开线索。

6. 放大机制：供应链合规疑点被海外媒体与英伟达回应共同放大〔G05、S11〕 事件经Wccftech和Tom’s Hardware报道后，被放入“美国出口管制未能阻止顶级AI硬件外流”的叙事中传播。 英伟达发言人对Tom’s Hardware表示，被转移的受控美国产品占已部署库存不足0.5%，并称走私是“沧海一粟”且已被两国政府拦截，但报道指出英伟达并未否认Lava的发现。 这种回应虽然淡化规模，却也确认了外界讨论的焦点从单一配置暴露转向受限芯片是否被转移、谁应承担供应链合规责任。

05如果你是……

董秘

  • 针对2026年8月Lava报告与海外媒体报道，梳理公司在境外业务、跨境云服务、国际投资者沟通材料中是否已披露算力资产合规风险，必要时补充说明采购来源与合规措施，避免信息不对称被解读为隐瞒。
  • 向IT与采购部门索取GPU设备清单及采购合同，核查是否涉及受美国出口管制的B300等型号，并评估潜在声誉与合规影响。

合规负责人

  • 依据美国出口管制政策与台湾相关刑事案件信息，调取所有高端GPU采购合同与贸易商资质文件，重点核查是否存在无法溯源或渠道不明的受限型号。
  • 检查运维系统（如DCGM Exporter）是否存在公网暴露、无鉴权等配置，要求IT部门提供外部可访问资产清单，并立即整改。

ESG 负责人

  • 结合本案中Lava通过公网接口识别GPU的事实，更新ESG报告中的“数据安全与合规”章节，说明算力资产采购与运维的合规管理措施。
  • 向供应链管理部门索要高端硬件采购的溯源与合规声明，纳入供应链ESG风险评估流程。

战略负责人

  • 参考本案台湾贸易商被指为走私链条一环的事实，要求对所有境外合作方、贸易商、分销商开展穿透式合规尽调，查验其白名单资格与历史合规记录。
  • 在新建或扩建数据中心选址决策时，将出口管制合规与运维安全纳入前置评估，避免因设备来源不明影响后续业务拓展与国际合作。

公关负责人

  • 制定针对Lava报告和海外媒体质疑的统一回应口径，明确说明公司对算力资产采购合规的立场，并在48小时内准备好应急声明。
  • 启动对国际主流科技媒体、行业分析师及关键利益相关方的舆情监测，及时收集并反馈外部关切，辅助管理层决策。

06来华外企自查清单

  1. 我们在中国境内采购和部署的高端算力设备（如GPU、服务器等）是否有受美国或其他国家出口管制的型号？采购合同、供应商资质、设备溯源文件是否齐全，最近一次合规核查是什么时候？是否符合《外商投资准入特别管理措施（负面清单）》及相关进口管理规定？
  2. IT部门是否定期检查关键运维系统（如远程管理工具、资产监控平台）是否存在公网暴露、弱认证或无鉴权等安全隐患？最近一次外部渗透测试和资产暴露面扫描报告是否已归档？整改流程是否符合《网络安全法》及《数据安全法》要求？
  3. 供应链管理部门是否要求所有高端硬件供应商、第三方贸易商和分销商出具合规承诺函及产品溯源证明？是否对渠道商开展了穿透式合规尽调？流程是否参考了《反不正当竞争法》和《进出口商品检验法》相关规定？
  4. 我们是否建立了应对被外部机构或媒体点名的快速响应机制？遇到合规质疑时，能否在48小时内完成内部核查并形成统一对外口径？负责部门和流程文件是否明确？
  5. 在对外披露（如海外业务、国际合作、融资材料、ESG报告）中，是否充分说明了算力资产采购、供应链合规和数据安全风险？最近一次材料更新和合规审查时间是什么时候？
  6. 针对出口管制、供应链合规等敏感议题，我们是否有专门的舆情应急预案、指定发言人和演练记录？相关预案是否结合了中国市场的监管和媒体环境特点？
  7. 我们在在建项目、关键零部件采购、重大合同签署等环节，是否设有合规审查节点？审查标准是否与最新国际出口管制、反洗钱及中国本地法律法规同步更新？
  8. 近期是否委托第三方对数据中心及关键IT资产进行安全与合规评估？评估中发现的问题是否已完成整改并有闭环记录？
