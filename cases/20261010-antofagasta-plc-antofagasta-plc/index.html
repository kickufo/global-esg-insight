01一句话结论

英国基本金属矿企Antofagasta Plc在智利Centinela铜矿因同岗不同酬争议遭709名工人罢工并升级为绝食抗议，核心诉求是消除不同集体合同下的薪酬差距。对于中国出海企业，结构性用工差异一旦被工会定性为“歧视”，将迅速演变为声誉与经营双重风险。

02发生了什么

2026年9月下旬，智利北部Centinela铜矿的劳资矛盾公开化。该矿由Antofagasta Minerals运营，后者是伦敦上市的Antofagasta Plc的智利分支。两家工会——Minera Esperanza与Distrito Centinela——以98.73%的高票率通过罢工授权，成员合计708人，约占矿区员工22%。

争议焦点在于，同一矿区内不同集体合同下的同岗员工，薪酬与福利存在显著差距。工会将这种差异定性为“歧视”，要求公司消除不平等，并建立机制防止未来再出现类似问题。公司则否认歧视，解释差异源自以往谈判历史，并提出加薪2%及23,000美元奖金作为最终方案。

9月23日，工会拒绝了公司的方案，理由是未能解决既有的薪酬差距。根据智利劳动法，集体谈判进入由劳动部下属劳工局主持的强制调解阶段。10月6日，调解无果，罢工期限定在午夜。10月7日早上8点，罢工正式启动。

罢工行动迅速升级。709名工人停工，50名抗议者在首都圣地亚哥金融区扎营，另一批人在北部矿区持续行动。部分工人发起绝食抗议，这在智利矿业纠纷中极为罕见，仅有2020年Codelco和2015年BHP矿区的先例。智利主要工会联合会主席José Manuel Díaz公开呼吁Luksic家族（公司实际控制方）参与有尊重的对话。

面对绝食和舆论压力，Antofagasta公司选择沉默，拒绝对绝食置评，并维持官方产量预测。工会方面则警告，随着罢工持续，运营影响将加剧，预计到2026年11月铜产量将下降50%。该矿2026年上半年产铜97,100吨，而铜价正处于高位，上月接近每吨15,000美元。

同期，BHP集团Escondida铜矿的监管人员也启动了强制调解以避免罢工，两场劳资行动反映出在铜价高企背景下，工人要求分享超额利润的诉求正在行业内蔓延。此外，智利失业率升至9.6%，为五年来最高，社会就业压力与工会动员能力相互作用，使本次事件更易获得公众关注。

截至目前，Antofagasta未在“防止歧视机制”这一核心诉求上让步，劳资僵局仍在持续，罢工及绝食抗议已成为智利矿业和国际投资界关注的焦点。

04风险是怎么形成的

议题定位：主议题 S02 劳动权益与薪酬；副议题 S04 歧视与骚扰

根因链：同一矿区长期并存不同集体合同，薪酬福利由历史谈判分别形成 → 同岗员工之间出现被工会认定为不公平的薪酬福利差距 → 公司把差异解释为过往谈判结果，并以加薪和奖金方案收口谈判 → 工会认为方案没有修复既有差距，也没有防止新差距的机制，拒绝接受 → 强制调解失败后罢工启动，绝食和首都扎营把劳资争议推向全国舆论 → 停工、产量下滑预期和声誉压力同步上升

1. 结构性根因：分散的集体合同把同一岗位切成不同薪酬轨道〔S02〕 Centinela铜矿内存在不同集体合同，公司称薪酬和福利差异来自以往谈判历史，这说明同一矿区的用工条件并非由统一岗位价值体系决定，而是由不同谈判批次沉淀下来。当历史合同差异叠加到同一岗位上，企业容易把它视为谈判遗留问题，员工则会把它理解为“做同样工作却拿不同待遇”的分配不公。这种结构一旦没有清晰的校准机制，差距会从合同技术问题转化为劳动权益冲突。

2. 行为层：同岗低薪被工会定性为歧视（指控，尚未裁决）〔S02、S04〕 两家工会称，其成员与另一工会中从事相同工作的员工相比，薪酬和福利更低，并把核心诉求界定为结束薪酬福利差距。工会还要求建立机制，防止下一轮集体合同中再次产生新的差距，这表明争议并不只是一次性涨薪，而是对企业薪酬规则公平性的挑战。公司否认歧视，称差异源自过往谈判，并提出2%加薪和23,000美元奖金作为最终方案。

3. 直接诱因：最终报价没有回应“修复差距”这一核心诉求〔S02〕 9月23日，工会拒绝公司的最终方案，理由是该方案没有解决既有薪酬差距。这使谈判焦点从金额多少转为公司是否承认并处理历史差距，单纯加薪和奖金无法替代对同岗薪酬结构的调整。随后，智利劳动法下由劳工局主持的强制调解结束但未达成一致，罢工期限被推进到午夜，冲突进入公开化和对抗化阶段。

4. 外部环境：高铜价与矿业劳工动员放大了分配预期〔S02〕 报道提到，铜价此前接近每吨15,000美元，矿业劳动紧张关系随之上升，工人要求更多分享行业超额收益的情绪增强。同期，BHP集团Escondida铜矿监管人员也进入强制调解以避免罢工，显示类似劳资压力并非孤立发生在Centinela一处矿区。智利失业率升至9.6%并达到五年来高位，使劳动议题更容易获得社会关注，也提高了工会行动的公共能见度。

5. 应对失当：对绝食抗议保持沉默削弱了降温空间〔S02〕 罢工启动后，部分工人发起绝食抗议，50名抗议者在圣地亚哥金融区扎营，另有人员在北部矿区行动，使事件从矿区内部纠纷转入首都公共空间。面对绝食和舆论压力，Antofagasta拒绝对绝食置评，同时维持官方产量预测，这种处理方式没有公开回应工会最具情绪动员力的诉求。智利主要工会联合会主席José Manuel Díaz公开呼吁Luksic家族参与有尊重的对话，说明争议已经上升到实际控制方声誉层面。

6. 放大机制：停工、绝食和产量预期把劳资争议转化为经营风险〔S02〕 teleSUR报道称，停工涉及709名操作人员，约占Centinela矿区总员工的22%，这使薪酬争议直接影响生产连续性。工会警告，若罢工持续，运营影响将随时间加剧，并预计到2026年11月铜产量将下降50%，这一说法来自工会而非已确认的实际损失。公司维持产量预测，但公开报道未显示其已在“防止歧视机制”这一核心诉求上让步，劳资僵局因此继续维持在高曝光状态。

05如果你是……

董秘

  • 针对709名工人罢工及绝食抗议，要求在2026年10月底前补充ESG报告与年度报告中的“重大劳资纠纷”披露，明确说明薪酬结构争议及潜在影响。
  • 向投资者关系团队收集伦敦及智利主流财经媒体报道，整理投资人关切点，并在下一季度业绩说明会上准备应答要点。

合规负责人

  • 在2026年10月15日前，组织法律团队复核所有现行集体合同，识别是否违反智利劳动法关于同工同酬和反歧视的条款，形成法律风险评估报告。
  • 向人力资源部门发函，确认是否有员工或工会已向智利劳动监察机构或法院递交正式申诉，若有，及时准备应诉材料。

ESG 负责人

  • 要求在2026年第四季度ESG报告中，披露多合同结构导致的薪酬差异、工会诉求及公司拟采取的整改措施。
  • 督促供应链部门在年底前完成对所有海外工厂和矿区的集体合同梳理，评估是否存在类似薪酬差异风险。

战略负责人

  • 指示并购与投资团队在未来项目尽调中，增加对目标企业历年集体合同和工会关系的专项审查，防止遗留结构性薪酬差异。
  • 结合BHP Escondida铜矿同期调解案例，要求市场分析部门在2026年内完成区域主要竞争对手薪酬政策与集体谈判动态的对标分析。

公关负责人

  • 在2026年10月中旬前，制定关于“同岗不同酬”争议的媒体回应口径，强调历史合同成因及公司致力于公平的立场。
  • 实时追踪teleSUR、The Rio Times等媒体及工会联合会主席José Manuel Díaz的公开表态，准备与当地社区和工会代表的沟通材料。

06出海智利中企自查清单

  1. 我们是否已对所有在智利的集体合同进行梳理，并确认同一岗位员工在不同合同下的薪酬与福利差异？最近一次比对和内部评估是由哪个部门负责，时间是什么时候？
  2. 我们的人力资源部门是否掌握并遵守智利《劳动法》（Código del Trabajo）关于同工同酬、反歧视和集体谈判的具体要求？相关合规文件和培训记录是否齐全？
  3. 我们是否建立了与智利工会（Sindicatos）定期沟通和协商的机制？最近一次与工会的正式会谈纪要和议题归档是否可查？
  4. 我们对在建项目、当地工厂或关键零部件供应链中的外包和劳务派遣安排，是否已核查其用工合规性，并留存了智利劳工局（Dirección del Trabajo）相关核查或备案文件？
  5. 我们是否了解并遵循智利政府采购、招投标或主要客户对外资企业劳工政策的合规要求？相关投标文件和客户合规承诺书是否包含用工公平条款？
  6. 我们是否有机制监测智利主要工会联合会（CUT）及地方工会的动态，及时识别潜在劳资纠纷信号？负责部门和信息收集渠道是否明确？
  7. 我们是否评估了企业在智利社区关系和媒体舆论中的形象，特别是在薪酬公平、工人权益等议题上的风险点？最近一次危机公关预案演练或媒体监测报告是什么时候完成的？
  8. 我们是否针对智利多元文化和宗教习惯，对员工管理、福利政策和工会协商方式进行了本地化调整？相关政策文件和员工反馈渠道是否畅通？

07时间线

  1. 2026-09Centinela两家工会在9月下旬以全员投票、98.73%赞成票授权罢工。
  2. 2026-09-23工会以未解决既有薪酬差距为由，拒绝公司提出的最终方案（公司方案含加薪2%及23,000美元奖金[S1]）。
  3. 2026-10-06由劳动部下属劳工局主持的强制调解在罢工前的周二结束，未达成协议，罢工期限定在午夜。
  4. 2026-10-07调解失败后，罢工被定于10月7日周三早上8点开始。
