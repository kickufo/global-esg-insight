01一句话结论

美国游戏与数字娱乐平台Roblox因未成年人保护措施被美国亚利桑那州总检察长调查，并面临印尼政府本地化与合规整改压力，显示儿童安全已成为中国出海数字平台不可回避的合规底线。

02发生了什么

Roblox是一家总部位于美国的在线游戏平台，其独特之处在于用户既可以游玩，也能用平台工具自主创作虚拟世界。平台内建有虚拟货币和交易系统，形成了创作者经济生态。正因如此，Roblox在全球未成年人中极受欢迎。据报道，其用户以未成年人为主，其中超过五分之一未满9岁。

随着用户规模扩大，平台面临的风险也逐步暴露。2026年，亚利桑那州总检察长办公室针对Roblox发起调查，指控其未采取“基本预防措施”防范不适合年龄的内容、暴力与剥削，导致儿童用户暴露于不安全环境。总检察长办公室表示，2026年内多次就上述指控向Roblox索取相关资料，但公司“未能提供完整答复”。

这一调查在2026年10月16日迎来关键转折。当天，亚利桑那州总检察长Kris Mayes正式向法院提出申请，请求强制Roblox提交涉及未成年用户安全的关键数据，并主张在公司完全配合前以藐视法庭论处。这意味着，原本停留在监管问询层面的沟通，已升级为司法强制程序。相关报道未披露Roblox对此的具体公开回应。

与此同时，Roblox在东南亚市场也遭遇合规压力。印尼通信与数字部长Meutya Hafid亲赴美国硅谷，与Roblox首席执行官David Baszucki会面，提出三项要求：一是在雅加达设立办公室，二是安置印尼本地高管，三是严格遵守印尼法规并加强儿童保护。印尼方面的合规要求有明确法规支撑——《PP TUNAS》专门针对电子系统中的儿童保护，要求平台实施基于年龄的访问控制、限制高风险沟通并建立可问责的监督机制。

评论文章进一步指出，平台上儿童面临的风险包括网络欺凌、心理操纵、诈骗、不当内容暴露以及性剥削者的接近。文章强调，设立办公室和本地高管只是“物理存在”，真正的安全成效要看举报处理量、处置时效和年龄限制的实际有效性。

截至目前，Roblox同时面对美国州级的司法强制取证压力与印尼市场的本地化和合规整改要求。两地政府均未披露公司已作出的具体整改承诺或公开回应。

04风险是怎么形成的

议题定位：主议题 S09 消费者权益与营销；副议题 S08 产品质量与安全（含召回）、G07 公司治理与高管不当行为

根因链：未成年人占多数且低龄用户比例高 → UGC虚拟世界、聊天、交易和创作者经济叠加 → 年龄分级、内容治理和高风险沟通控制压力上升 → 被亚利桑那州总检察长指未采取基本预防措施且资料答复不完整 → 美国司法强制取证风险与印尼本地化、儿童保护整改压力同步出现

1. 结构性根因：儿童用户占比高，把一般平台治理问题转化为未成年人保护问题〔S09、S08〕 Roblox的多数用户是未成年人，且超过五分之一用户未满9岁，这使平台安全缺陷更容易被监管界定为儿童保护问题，而不是普通用户体验问题。低龄用户对不当内容、陌生人接触、诈骗和心理操纵的识别能力较弱，平台一旦提供开放互动环境，就需要承担更高强度的预防和监护责任。这种用户结构决定了风险不只来自个别内容或个别玩家，而是来自平台面向儿童大规模运营的基本条件。

2. 商业模式根因：开放创作、社交互动和虚拟交易叠加，扩大了安全治理半径〔S09、S08〕 Roblox不是单一游戏，而是允许用户游玩、创作虚拟世界、设计角色、与他人互动并参与虚拟货币和交易的数字平台。这种类似“数字城市”的结构让内容、社交、消费和创作者经济同时发生，平台需要同时治理年龄适配、内容审核、沟通边界和交易风险。当产品功能鼓励长时间停留、跨语言互动和创作者生态扩张时，儿童安全控制如果不能嵌入设计前端，风险就会在多个功能入口同时出现。

3. 治理层：跨国平台的本地责任链不足，削弱监管沟通和问责闭环〔G07、S09〕 印尼通信与数字部长Meutya Hafid赴美国硅谷会见Roblox首席执行官David Baszucki，并要求公司在雅加达设立办公室、安置印尼本地高管、遵守印尼法规并加强儿童保护，说明当地监管者认为现有责任接口不足以支撑有效问责。报道同时指出，设办公室和本地高管只是物理存在和组织结构，真正的安全成效仍要看举报处理、处置速度和年龄限制的有效性。这反映出的治理问题不是单纯有没有当地地址，而是平台能否把儿童保护责任落实到可审计、可追责、可持续运行的内部机制。

4. 直接诱因：被指未采取基本预防措施并造成儿童不安全环境（指控，尚未裁决）〔S09、S08〕 亚利桑那州总检察长办公室在调查中指称，Roblox未采取防范不适合年龄内容、暴力和剥削的“基本预防措施”，从而为儿童创造了不安全环境。这些说法目前是监管调查中的指控，来源未显示法院已就相关实体问题作出裁决。由于指控直接指向未成年人接触内容和遭受剥削的风险，冲突从平台治理争议升级为儿童安全与消费者保护争议。

5. 应对失当：被指资料答复不完整，使监管问询升级为司法强制程序（指控，尚未裁决）〔G07、S09〕 亚利桑那州总检察长办公室称，其在年内多次要求Roblox提供与指控有关的信息，但公司“未能提供完整答复”。这一说法仍属于监管方表述，来源未披露Roblox对此的具体公开回应或法院最终认定。在监管调查中，信息提供不完整会削弱监管者对企业自我纠偏能力的信任，并促使对方转向法院强制提交数据。

6. 放大机制：儿童安全议题跨司法辖区扩散，形成美国司法压力与印尼合规压力叠加〔S09、G07〕 亚利桑那州总检察长Kris Mayes已请求法院强制Roblox提交涉及年轻用户安全的关键数据，并主张在公司完全配合前以藐视法庭论处。与此同时，印尼以《PP TUNAS》为依据，要求电子系统平台实施基于年龄的访问控制、限制高风险沟通并建立可问责的监督机制。同一儿童安全问题因此不再局限于单一市场投诉，而是被不同国家和地区的监管者分别转化为司法取证、本地化组织设置和合规整改要求。

05如果你是……

董秘

  • 针对2026年10月16日亚利桑那州总检察长请求法院强制取证的事实，建议立即调阅公司在美国各州的监管问询与司法程序登记表，核查是否有类似未成年人保护调查或强制取证风险未在年度报告和投资者关系材料中披露。
  • 关注印尼通信与数字部长提出的本地化要求，建议与法务部门核实在印尼的实体设立与高管任命进展，及时更新对外披露材料，说明公司在新兴市场的合规布局。

合规负责人

  • 针对亚利桑那州总检察长办公室多次索取资料但公司“未能提供完整答复”的情况，建议复盘所有涉及未成年人保护的监管问询处理流程，重点检查数据调取、答复时限与责任人分工，查阅2026年内所有与未成年人保护相关的监管函件与公司回复。
  • 结合印尼《PP TUNAS》法规，要求法务团队梳理公司在印尼的产品与服务是否已纳入该法规要求的年龄核验、沟通限制与监督机制，并将合规条款纳入与第三方创作者的合同模板。

ESG 负责人

  • 结合印尼部长提出的儿童保护要求，建议对公司全球未成年人用户保护政策进行重大性评估，补充披露举报处理量、处置时效与年龄限制有效性等关键绩效指标，接受第三方审计结果纳入年度可持续发展报告。
  • 针对平台开放UGC与社交功能，建议与产品和风控部门核查现有内容审核与举报机制，评估是否覆盖所有高风险场景，并将儿童保护纳入供应链管理要求。

战略负责人

  • 结合印尼政府要求设立本地办公室与高管的事实，建议对所有高监管市场（如印尼、美国各州）梳理本地实体与管理团队配置，制定本地化组织与应急响应方案，优先推进在重点市场的实体设立与高管派驻。
  • 针对亚利桑那州司法强制取证风险，建议与法务、数据合规部门联合评估公司在各主要市场的数据留存、跨境调取与合规响应能力，必要时调整市场进入节奏或合作方选择标准。

公关负责人

  • 针对2026年10月16日亚利桑那州总检察长向法院申请强制取证，建议提前准备未成年人保护相关司法程序的媒体回应口径，重点覆盖美国地方主流媒体如KJZZ。
  • 结合印尼通信与数字部长要求设立雅加达办公室及本地高管，建议优先监测印尼《共和国报》网络版等主流媒体，并与当地儿童权益组织建立沟通渠道。

06出海美国中企自查清单

  1. 我们是否已建立针对美国各州总检察长办公室、联邦贸易委员会（FTC）等监管机构的问询、调查和司法程序登记台账？最近一次更新和核查时间是什么？涉及未成年人保护的历史问询是否有完整留档与答复记录？

  2. 我们在美国本地的产品、服务或平台是否已针对《儿童在线隐私保护法案》（COPPA）等法规要求，建立了适龄用户识别、数据收集与家长同意机制？相关合规文件和操作流程由哪个部门负责维护？

  3. 我们对美国出口产品或在美在建项目的二级、三级供应商，是否核查其用工合规证明、未成年人保护政策及相关培训记录？最近一次合规核验是什么时候？由哪个部门负责？

  4. 我们在美国当地工厂、分支机构或项目团队是否已建立与工会、社区组织的沟通机制？是否有针对未成年人雇佣、实习或志愿者的合规指引，并定期接受社区或第三方监督？

  5. 我们是否已对美国市场的主要客户、渠道或政府采购方的合规要求进行梳理，特别是涉及未成年人保护、数据安全和内容审核的条款？相关合同和招投标文件是否由法务团队定期复查？

  6. 我们的数据留存、跨境调取与应急响应流程，是否能满足美国监管机构（如州总检察长办公室、FTC）对未成年人相关数据的调阅、取证和合规披露要求？最近一次流程演练或合规自测时间是什么？

  7. 我们在美国市场的品牌传播、媒体关系和危机公关预案，是否覆盖了地方主流媒体、儿童权益组织和非政府组织的关注点？是否有专人负责监测和回应相关议题？

  8. 我们是否对美国各州的文化、宗教和社区习惯进行了本地化适配，特别是在内容审核、用户互动和社区管理方面？相关政策和操作手册是否已落地到一线团队？
