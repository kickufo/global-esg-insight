01一句话结论

德国汽车制造商大众集团因成本压力拟冻结全球66万员工工资至2030年，遭德国和捷克工会强烈反对并面临罢工威胁。对中国出海企业而言，跨国人力政策“一刀切”极易引发本地劳资冲突，需警惕集体合同与工会动员的刚性约束。

02发生了什么

2026年10月，德国《南德意志报》首先披露了一份大众集团的内部文件，显示公司计划将全球约66万名员工的工资冻结至2030年。很快，大众全球职工委员会向外界确认，已收到执董会下达的相关指令。根据指令，各地人事负责人被要求执行“零轮”加薪，即薪酬停留在当前水平，暂停一切涨幅。该措施自10月初生效，属于第四季度一揽子全球管理规则的一部分，内容还包括下调浮动薪酬、特别支付、福利及岗位调整。

消息曝光后，立即在德国和捷克两地引发强烈反弹。德国方面，职工委员会公开批评该做法“荒谬”，并预测会遭遇强烈抵抗，认为该计划“相当不现实”。德国金属业工会 IG Metall 的发言人强调，大众的薪酬走势应由谈判桌决定，而不是执董会会议室里的政令。据《南德意志报》测算，若工资冻结至2030年，受影响员工的实际收入将因通胀缩水约10%。大众在德国雇用约27.5万人，其中约13万人适用公司内部集体合同，奥迪、保时捷和 MAN 的员工则适用 IG Metall 的行业性集体协议，预计工资冻结将成为劳资谈判的核心议题。

捷克方面，风波迅速波及大众旗下斯柯达品牌。斯柯达在捷克的三家工厂共雇用约3.65万人（含劳务派遣人员），分布在姆拉达-博莱斯拉夫、克瓦西尼和弗尔赫拉比。斯柯达工会随即表态，若母公司坚持冻结工资至2030年，将举行罢工。捷克金属工会（OS KOVO）主席雅罗斯拉夫·波夫希克明确表示，斯柯达员工不会接受冻结工资、取消奖金和津贴，并警告一旦出现裁员，三家工厂的生产都可能停摆。工会反对的理由之一是斯柯达经营状况良好，利润率高于集团内部分其他品牌，不应为集团整体节支“买单”。

大众集团方面则保持低调。公司拒绝对其称为“猜测”的内容置评，仅有发言人表示，任何关于人力成本的提议都将在本周晚些时候的新一轮谈判中讨论。斯柯达方面未立即回应工会诉求，但现有的集体合同有效期至2027年3月31日。

截至目前，事件仍停留在工会威胁和企业表态阶段，尚未发生实际罢工或生产中断。双方正为即将到来的劳资谈判积累筹码。大众首席执行官奥利弗·布卢梅正推进被称为公司历史上最激进的重组，以应对电动化转型的高昂代价、关键市场需求走弱以及来自中国制造商的激烈竞争。工资冻结成为这场重组中最敏感、最具爆发力的议题之一。

03代价

  • 罢工威胁：斯柯达工会已公开威胁罢工，若母公司坚持冻结工资，三家捷克工厂生产可能停摆。
  • 劳资谈判升级：德国和捷克工会均已将工资冻结列为核心谈判议题，劳资关系紧张。
  • 声誉影响：大众被工会和职工委员会公开批评为“荒谬”“不现实”，面临舆论压力。
  • 实际收入下降：据测算，若工资冻结至2030年，员工实际收入可能缩水约10%。
  • 经济损失与法律风险：如罢工成真，斯柯达三厂生产停摆将造成产量与交付损失，单方面推行政策可能引发劳动争议、仲裁或诉讼。
  • 公开报道未披露：罚款、赔偿、股价波动、审批延误、评级调整、人员伤亡等。

04风险是怎么形成的

议题定位：主议题 S02 劳动权益与薪酬；副议题 G07 公司治理与高管不当行为

根因链：电动化投入、高成本、需求走弱和中国车企竞争压缩利润空间 → 管理层将全球人力成本列为重组降本对象 → 拟以全球统一规则冻结工资并下调浮动薪酬、福利和岗位安排 → 该做法触碰德国、捷克既有集体合同和工会谈判机制 → 工会将其视为单方面强加成本并公开反对 → 斯柯达工会发出罢工威胁，德国谈判议题升级并形成舆论压力

1. 结构性根因：转型成本和竞争压力被集中传导到工资成本〔S02〕 大众正在推进被称为公司历史上最激进的重组，背景是电动化转型成本高、关键市场需求走弱，以及来自中国制造商的激烈竞争；这些因素共同压缩欧洲车企利润空间，使管理层更倾向于从固定人力成本中寻找确定性节约。 捷克报道还提到，大众面临中国制造商竞争、高运营成本和美国关税，因此准备大规模重组，这说明工资冻结并非孤立的人事动作，而是集团降本逻辑的一部分。

2. 治理层：全球一刀切规则与本地集体谈判结构发生错位〔G07、S02〕 大众在德国有约27.5万名员工，其中约13万人适用公司内部集体合同，奥迪、保时捷和 MAN 员工还受德国金属业工会 IG Metall 行业协议覆盖；这意味着薪酬不是单纯的总部预算科目，而是嵌入集体谈判和工会授权的制度安排。 斯柯达现有集体合同有效期至2027年3月31日，母公司若以集团统一口径处理捷克工资、奖金和津贴，天然会与当地合同周期和工会代表权发生摩擦。

3. 直接诱因：内部文件披露全球冻结工资至2030年〔S02〕 德国《南德意志报》据内部文件首先披露，大众拟将全球约66万名员工工资冻结至2030年；大众全球职工委员会随后称已收到来自执董会的相关指令。 指令要求各地人事负责人执行“零轮”加薪，即薪酬维持现有水平并暂停涨幅，同时还据称包括下调浮动薪酬、特别支付、福利和岗位安排，因而直接触及员工现金收入和福利预期。

4. 行为层：被指绕开谈判桌推行薪酬冻结（指控，尚未裁决）〔S02、G07〕 德国金属业工会 IG Metall 表示，大众薪酬走势应在谈判桌上决定，而不是由执董会会议室下达政令；这一表述反映工会将该方案理解为对集体谈判程序的单方面压制，但公开报道未显示已有司法或仲裁裁决。 大众拒绝评论其称为“猜测”的内容，仅表示任何人力成本提议会在稍后的新一轮谈判中讨论，因此企业立场与工会指控之间仍处于谈判和舆论交锋阶段。

5. 外部环境：通胀和品牌间利润差异削弱员工让步空间〔S02〕 据《南德意志报》测算，若到2030年没有加薪，受影响员工实际收入将因通胀缩水约10%；因此，名义工资不降也会被员工视为实质性减薪。 在捷克，工会反对的一个关键理由是斯柯达经营仍然盈利，且利润率高于集团内部分其他品牌，员工因而更难接受以自身工资、奖金和津贴为集团整体节支买单。

6. 放大机制：工会网络把内部降本方案转化为跨国劳资冲突〔S02〕 德国职工委员会公开批评该做法“荒谬”“不现实”，并预期会遭遇强烈抵抗，使原本的内部成本管理议题迅速进入公共舆论和集体谈判场域。 捷克金属工会 OS KOVO 主席雅罗斯拉夫·波夫希克表示，斯柯达员工不会接受冻结工资、取消奖金和津贴，并警告若出现裁员，斯柯达三家捷克工厂生产都可能停摆；至此，风险从薪酬争议外溢为罢工威胁和潜在生产中断。

05如果你是……

  • 在2026年年度报告披露前，补充说明工资冻结政策对集团盈利、现金流和长期人力成本的情景分析。

合规负责人

  • 要求各地法务在2026年四季度内完成对所有在建和已签集体合同的逐条审查，明确冻结工资措施是否需与工会协商或重新谈判。
  • 针对德国IG Metall和OS KOVO的反对意见，向总部提交法律意见书，评估推行统一政策的合规风险及潜在诉讼点。

ESG 负责人

  • 建议在2026年度可持续发展报告中，单独披露工资冻结对员工福祉和劳资关系的影响，并说明应对通胀的补救措施。
  • 针对斯柯达盈利高于集团其他品牌的争议，补充说明集团内部成本分担与员工激励的公平性考量。

战略负责人

  • 要求人力资源部门在2026年四季度内评估各地工会的谈判底线，制定多地工厂产能调整与人力成本优化的多方案备选。
  • 针对斯柯达三厂罢工风险，制定生产转移、关键零部件调配和客户交付优先级的应急计划。

公关负责人

  • 在2026年四季度前，准备针对德国和捷克主流媒体的统一回应口径，强调集团与工会持续对话、尊重本地谈判机制。
  • 建议设立专门小组，实时监测工会、媒体及社区舆情，及时向管理层报告重大负面动态。

06出海德国中企自查清单

  1. 我们是否已核查所有在德国本地雇佣员工的劳动合同、集体协议，确保符合《德国集体谈判法》（Tarifvertragsgesetz）及相关行业工会（如IG Metall）的要求？最近一次合同审查和工会沟通记录存档于何处？

  2. 我们在德国的薪酬调整、奖金发放和福利政策，是否有与本地工会或职工代表委员会（Betriebsrat）进行正式协商并留存会议纪要？涉及重大变动时，是否遵循了德国《工会参与法》（Betriebsverfassungsgesetz）的程序？

  3. 我们在德国的用工政策（包括劳务派遣、临时工和外包人员）是否满足德国本地劳工法规，尤其是针对外资企业的合规要求？相关合规证明和外包合同是否定期更新？

  4. 我们是否建立了与德国主要工会（如IG Metall）和职工代表的定期沟通机制？最近一次与工会的正式会议或谈判发生在什么时候，会议纪要是否归档？

  5. 我们在德国参与政府采购、招投标或与大型本地客户合作时，是否有被要求提交用工合规、集体合同执行和劳资关系稳定性的证明材料？这些材料由哪个部门负责准备和更新？

  6. 我们是否评估过德国本地媒体、非政府组织和社区对企业用工政策的关注点，并建立了舆情监测和危机应对流程？相关报告和应急预案是否每年更新？

  7. 我们是否了解德国不同地区（如巴伐利亚、下萨克森等）在劳工关系、工会影响力和文化习惯上的差异，并据此调整本地工厂或项目的人力政策？相关调研报告归档于何处？

  8. 我们在德国的高管或人力资源负责人，是否定期接受德国劳动法、工会谈判和外资企业合规方面的专项培训？最近一次培训的内容和参与人员名单是否有记录？
